 # 321code Studio

## Uruchamianie

Po instalacji:

    321 studio

Aliasami są 321 gui i 321 app. Studio jest lokalną aplikacją Tkinter i nie wymaga konta ani połączenia z usługą zewnętrzną. Tkinter musi być dostępny w instalacji Pythona; w samodzielnym EXE wymagane jest dołączenie bibliotek GUI w procesie budowania.

## Moduły

- Pulpit — szybki dostęp do narzędzi.
- Projekty — tworzenie prostego projektu .321 i otwieranie folderów.
- 321 AI Studio — kreator modeli, czat, uruchamianie treningu i wybór projektu.
- Security Scanner — lokalna analiza folderu i podstawowa analiza publicznej strony WWW.
- Język 321code — uruchamianie plików .321.
- Ustawienia — informacje o lokalnym środowisku.

## Ograniczenia

Studio to pierwsza wersja środowiska, a nie pełne IDE. Edytor kodu z podświetlaniem składni, debugger, terminal wbudowany, menedżer paczek i pełne zarządzanie zależnościami są osobnymi etapami rozwoju. Nie wszystkie narzędzia są jeszcze osadzone wewnątrz jednego okna — AI Creator i chat są osobnymi oknami.
